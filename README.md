# Student Performance Dashboard

An interactive dashboard built using Python and Plotly Dash to analyze student performance data.

## Features
- Interactive Scatter Plot
- Bar Chart Analysis
- Multi-panel Dashboard
- Correlation Heatmap
- Student Performance Insights

## Technologies Used
- Python
- Pandas
- Plotly
- Dash
- NumPy

## Installation

```bash
pip install -r requirements.txt
python dashboard.py
